# Capsul Box

Android-планшет как экран и пульт для игрового ПК. **Capsul Box работает вместе с [Капсулой](https://github.com/Wikaar/Wikar-DynamicIsland)** — Dynamic Island для Windows: Капсула знает, во что ты играешь, какой FPS и сколько заряда у наушников, а Capsul Box показывает это на планшете рядом с монитором.

Связь с ПК — по USB-кабелю или по Wi-Fi в домашней сети. Без облака и аккаунтов.

## Что на планшете

| Страница | Что на ней |
| --- | --- |
| Главная | Часы и дата, погода, плеер (обложка, перемотка, громкость), CPU, GPU, RAM, сеть, FPS, заряд устройств |
| Игра | FPS и название игры, загрузка и температура GPU и CPU, график, заряд, Discord: микрофон, звук, выход |
| Процессы | Самые тяжёлые программы, подробности, завершение процесса |
| Кнопки | Сетка кнопок: программы, ссылки, сочетания клавиш, блокировка, выключение экрана |
| Звук | Громкость каждой программы, выбор аудиовыхода (наушники ↔ колонки) |
| Discord | Голосовой канал и участники, серверы и вход в каналы, уведомления |

Запустил игру — планшет сам открывает «Игру» и держит её, вышел — возвращается обратно.

## Что даёт Капсула

- **FPS и название игры** из игрового мониторинга Капсулы (PresentMon).
- **Начало и конец игры** — для автоперехода на страницу «Игра».
- **Заряд устройств**, которые Windows не показывает: JBL Quantum через QuantumENGINE, гарнитуры через HeadsetControl, а также Bluetooth.

Без Капсулы Capsul Box тоже работает, но без FPS, автоперехода и заряда этих устройств. Нужна Капсула **v0.32.3 или новее** с включёнными «Заряд устройств» и «Мониторинг в игре».

## Как устроено

```
Планшет (APK Capsul Box) ⇄ USB или Wi-Fi ⇄ агент Capsul Box на ПК ⇄ Капсула
```

- **APK** — полноэкранная панель (Kotlin + WebView), Android 5.0 и новее.
- **Агент** — программа для Windows 10/11 x64, иконка в трее, настройки в браузере на `http://127.0.0.1:8775`. Настройки открываются только с этого компьютера; планшет подключается по USB или, если включить, по Wi-Fi, соединение шифруется.
- **Капсула** раз в секунду передаёт агенту FPS и раз в 30 секунд — заряд устройств.

## Установка

Готовые файлы — в разделе **Actions → последний успешный запуск build → Artifacts**:

1. `capsulbox-agent-win-x64` — распаковать, например, в `C:\CapsulBox` и запустить `CapsulBoxAgent.exe`. Сборка пока без цифровой подписи: в окне SmartScreen нажать «Подробнее» → «Выполнить в любом случае».
2. `capsulbox-apk` — скопировать APK на планшет и установить (разрешить установку из неизвестных источников).
3. На планшете включить отладку по USB, подключить кабель и подтвердить запрос «Разрешить отладку по USB?». Агент сам найдёт планшет и откроет панель.

Discord подключается один раз в настройках агента (Общие → Discord): нужно своё бесплатное приложение в [Discord Developer Portal](https://discord.com/developers/applications) — пошагово в [docs/DISCORD.md](docs/DISCORD.md).

## Сборка

Всё собирается в GitHub Actions (`.github/workflows/build.yml`): APK и агент для Windows при каждом изменении в `main`. Агент — .NET 10, APK — JDK 17 и Android SDK 35.
